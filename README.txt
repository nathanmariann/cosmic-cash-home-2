COSMIC CASH — HOME PAGE PROTOTYPE

Files:
- index.html: page structure
- styles.css: responsive styling
- app.js: preview interactions

Open:
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html with Live Server, or double-click index.html to view it in a browser.

This version is a visual prototype using sample figures ($47,000 balance, $4,200 income, $2,800 expenses).
It does not connect to real financial accounts or perform transfers, bill payments, credit actions, or secure VPN transfers.

The layout is based more closely on the supplied Home Page PDF: a centered phone screen, Cosmic Cash header, purple total-balance panel, six circular quick actions (Credit, Pay Bills, Transfer Money, Cards, Savings, and Budget), income/expense tiles, analytics chart, bottom navigation, and lock control.

FINANCIAL GOALS: Open goals.html or click Goals in the home page bottom navigation. Includes savings and investment summary graphs, three example goal progress bars, and Add Goal form. Custom goals save in local browser storage only. All financial values are illustrative.

Version 5: Savings and investment monthly vertical bar charts (June–November sample data). Individual goal progress bars remain below.
